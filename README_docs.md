# RaceDay Part 1 — Documentation

Copy these files into the repository's `/docs` folder:

1. `RaceDay_ERD.png` — ERD with six entities, PKs, FKs and cardinalities.
2. `RaceDay_API_Endpoint_Plan.md` — API endpoint plan for Part 2.
3. `RaceDay_Database.sql` — SQL Server schema and realistic seed data.

The SQL schema matches the ERD. Live weather is intentionally not stored as a database entity because it is obtained from an external weather service.
